Qual serviço escolher?

Para emagrecer de forma consistente, o acompanhamento nutricional, de preferência semestral. Para uma questão pontual, como exames alterados ou sintomas digestivos, a consulta única resolve.

Sim. A avaliação, o plano alimentar, os materiais e o suporte pelo WhatsApp são os mesmos.

Atende convênio?

Não. Todos os serviços são particulares. Os valores são informados pelo WhatsApp.
