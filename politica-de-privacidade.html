Política de privacidade

Como trato os seus dados neste site. Atualizada em outubro de 2026.

quem é a responsável

Este site pertence a Aline Fernanda de Souza dos Santos, nutricionista CRN-8 10069, com consultório na Av. Batel, 1230, Curitiba, PR. Para qualquer assunto sobre os seus dados, escreva para Alinefnn2@gmail.com.

quais dados o site coleta

O site não tem formulários e não pede dados pessoais. O contato acontece pelo WhatsApp, por telefone ou por e-mail, quando você decide falar comigo.

  • Contato pelo WhatsApp, telefone ou e-mail: as informações que você envia são usadas só para responder, agendar e realizar o seu atendimento.
  • Dados de navegação: se você aceitar os cookies de análise, o Google Analytics registra informações anônimas, como páginas visitadas, tempo no site e tipo de aparelho. Esses dados não identificam você.
  • Hospedagem: o servidor que hospeda o site pode registrar dados técnicos, como endereço IP, por segurança.

cookies

Cookies de análise só são ativados se você clicar em Aceitar no aviso que aparece no site. Se recusar, o site funciona normalmente. Você pode mudar a escolha a qualquer momento limpando os dados do site no seu navegador.

com quem os dados são compartilhados

Não vendo nem compartilho seus dados com terceiros para fins comerciais. Os serviços usados para o site funcionar, como hospedagem, Google Analytics e WhatsApp, seguem as próprias políticas de privacidade.

Os dados de saúde informados durante o atendimento seguem o sigilo profissional previsto no Código de Ética do Nutricionista e não passam por este site.

seus direitos

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir a confirmação, o acesso, a correção ou a exclusão dos seus dados, além de revogar consentimentos. Basta escrever para Alinefnn2@gmail.com.
